# BHQ観光おでかけ

BHQ（脳の健康指標）の結果や今日の調子から、出かける距離と場所の種類を決めて、47都道府県・150か所の観光名所をすすめるサイトです。

- 公開サイト：https://jin634666.github.io/bhq-kanko-odekake/
- このサイトではBHQを計測しません。クイックBHQドックなどで測った結果の数値を入れるか、調子（★1〜5）と3部位の高め・低めを選びます
- 入力はそのブラウザにだけ保存され、どこにも送りません
- 自動更新はしていません。名所の追加・修正は `js/spots.js` を書き換えて push します

## しくみ

| 入力 | 使い方 |
|---|---|
| 全脳（★） | 出かける距離。★5 遠征（300km以上）／★4 ちょっと遠出（100〜600km）／★3 いつもの範囲（150km以内）／★2 近場（60km以内）／★1 近所（30km以内）。★2・★1 は自然・水辺・庭園など回復しやすい場所を優先 |
| 社会性・認知制御・モニタリング | 高め・低めで場所の種類を決め、並び順を変える。低めの部位は、その部位のランクが A・B の名所を上に |

- BHQの数値を入れたときは、脳の健康点数・星・高め／低めをクイックBHQドックと同じ計算で出す（ΔBHQ = BHQ − 125 + 年齢×0.5）
- 名所ごとの A〜E ランク、点数の式、根拠の論文は `js/odekake.js`（`RANK_RULES`・`REFS`）。画面の「おすすめの決め方と根拠にした論文」にも出る
- 論文は脳のネットワークの働きや環境（自然・都市・新しい場所）の効果を調べたもので、BHQの値と出かけ先の相性を直接確かめたものではない。目安として使う

## ファイル

| ファイル | 内容 |
|---|---|
| `index.html` | 画面とデザイン |
| `js/app.js` | 入力・おすすめ・ランク一覧の表示 |
| `js/odekake.js` | 距離・範囲・3部位の決め方・ランクの計算・論文の一覧（このPC用の「BHQおでかけ_観光名所版」と同じ） |
| `js/spots.js` | 観光名所150か所（名前・都道府県・種類・おおよその緯度経度・4つの特徴・ひとこと） |

BHQを本物で計測できるのは、このPC用の版（`BHQおでかけ_観光名所版` の 起動.bat）です。
